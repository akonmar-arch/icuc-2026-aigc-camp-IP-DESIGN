# ICUC 2026 AIGC CAMP · IP DESIGN

IP课程第二部分：角色设计（下）。基于用户提供课件，整理为可浏览的AI角色设计教学网站。

## 内容

8个教学模块：AI工作流、人物定位、参考研究、生成与修订、三视图、表情与姿态、服装、设定包作业。

保留50页原课件、50张原始示范图片和5段内嵌视频。增补可复制的AI提示词、人工验收方法、作业与过程记录模板。所有提示词需要在使用的AI工具中执行。

## 使用

双击`index.html`或使用本地静态服务器。左右方向键切换章节；点击图片查看；课堂展示按钮可隐藏目录并放大文字。作业勾选保存在当前浏览器。

GitHub Pages发布来源为`main`分支根目录，使用`.nojekyll`直供静态文件。资源采用相对路径，支持仓库子目录网址。

## 教学改编

课件内容与案例保留来源页码。AI实操模板、检查清单与过程记录为课堂增补。人物探索阶段的风格与比例描述需选择一版定稿；场景作业数量与尺寸以Vincenzo老师原任务为准。

原课件中的工期比较按示意处理。授权相关课堂要求为记录参考来源、核对工具与素材使用条件，保留实际创作及人工修改过程。
