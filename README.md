# icuc-2026-aigc-camp-IP-DESIGN

IP角色设计课程网页，采用16:9画面和连续向下滚动阅读。

保留原PPT的48页内容及顺序（原第34页长视频、原第50页动画制作流程图已移除），加入30页角色设计理论，末尾追加12页IP设计方法论总结，共90页。新增内页沿用原PPT的蓝紫背景、黄色强调和白色正文。
