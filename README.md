# icuc-2026-aigc-camp-IP-DESIGN

IP角色设计课程网页，采用满宽16:9画面、连续向下滚动阅读，只面向桌面课堂展示。

课程按学习逻辑整理为88页：48张原课件页面、35页理论与章节导读、5页方法论实践工具。
原第34页长视频与原第50页动画制作流程图已移除，其余原课件图像和第45页动态图保留。
新增页面继续使用原课件的蓝紫背景、黄色强调与白色正文。

## 课程主线

1. 明确任务（第1—7页）：概念边界、设计简报与文化题材的条件分支。
2. 建立角色（第8—35页）：三大原则、角色内核、视觉识别、表演与制作可行性。
3. 拆解案例（第36—65页）：先读巴斯，再比较配角与群体，回收共同规则与个体差异。
4. 传统角色设计流程（第66—81页）：奶奶角色作为独立资料，按原课件顺序展示参考、草图、结构、线稿、配色、完成视图及配件细化。
5. 验证与交付（第82—88页）：通用IP延展规则、六步回顾、两轮验证、返回修改、交付清单、完整方案示范。

三大原则判断设计品质，六步方法组织工作，案例拆解帮助从作品中学习。
末尾方法论是本课归纳的实践工具，独有操作要点已并入前文，不再重复逐项讲解概念。
巴斯案例拆解与奶奶传统设计流程是两个独立教学环节：前者分析已有作品，后者讲解传统角色怎样一步步制作。虚构夜间导览员用于课堂迁移示范。
