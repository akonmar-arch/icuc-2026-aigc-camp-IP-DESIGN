# icuc-2026-aigc-camp-IP-DESIGN

IP角色设计课程网页，采用满宽16:9画面、连续向下滚动阅读，用于桌面课堂展示。

当前共82页：48张原课件页面与34页理论、案例分析及章节导读。第82页“把知识收成可执行的方法”为末页。
原第34页长视频与原第50页动画制作流程图已移除，其余原课件图像和第45页动态图保留。
新增页面沿用原课件的蓝紫背景、黄色强调与白色正文。

## 课程主线

1. 明确任务（第1—7页）：概念边界、设计简报与文化题材。
2. 建立角色（第8—35页）：三大原则、角色内核、视觉识别、表演与制作可行性。
3. 拆解案例（第36—65页）：巴斯、配角与群体的共同规则及个体差异。
4. 传统角色设计流程（第66—81页）：奶奶角色独立示范参考、草图、结构、线稿、配色、完成视图及配件细化。
5. 验证与交付（第82页）：保留“把知识收成可执行的方法”页，课程到此结束。

巴斯案例分析与奶奶传统流程为两个独立教学环节。
