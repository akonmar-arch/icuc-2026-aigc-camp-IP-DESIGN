# icuc-2026-aigc-camp-IP-DESIGN

IP角色设计课程网页「角色观察档案」。统一采用满宽16:9画面、连续向下滚动，面向桌面课堂展示；原课件图片保持比例并支持放大。

保留原PPT的49页内容及顺序（原第34页长视频已移除），加入30页角色设计理论，共79页。新增内页沿用原PPT的蓝紫背景、黄色强调和白色正文。核心理论采用关系图、流程线、表格与图像对照；案例原图均可完整查看。

页面包含记忆锚点观察、原色/灰度与缩小测试、目录关键词检索、大图缩放与动态过程图。支持键盘、Escape关闭与焦点返回，并尊重系统减少动态设置。没有顶部导航、备注或AI设计内容。

首屏优先加载，其他图像懒加载。54张静态图使用等尺寸WebP，静态图体积减少50.35%；原始图像保留用于放大。字体自托管Space Grotesk，中文使用系统字体。所有课程正文都在静态HTML中，JavaScript用于增强交互。

## 发布

GitHub Pages使用main分支根目录，静态资源均采用相对路径。根目录为本课角色设计内容，其他独立目录由各自课程维护。

`content.js` 是课程顺序与理论数据；`original-pages.js` 是重排的原课件文字；`media-manifest.js` 是图像尺寸和优化映射。修改内容后运行 `node tools/build.cjs` 重新生成 `index.html`。

设计以Awwwards、Webby、FWA的视觉、可用性、内容和交互要求为品质目标。实验室性能审计与内部检查不等同于奖项评审结果。
